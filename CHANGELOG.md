# Changelog

## 0.3.0 - 2026-10-25

- Added explainable tag, status, topic, and related-card suggestions.
- Added configurable alias dictionaries and confidence thresholds.
- Added a deduplicated JSONL review queue and batch review reports.
- Added semantic card-similarity and duplicate-pair detection.
- Added automatic application guidance for high-confidence classifications while preserving confirmation for destructive or publication actions.
- Expanded the test suite to 11 tests.

## 0.2.0 - 2026-10-25

- Renamed the project to Skill Cairn, with the Chinese name 积微.
- Renamed the CLI from `edist.py` to `cairn.py`.
- Changed the vault configuration file to `skill-cairn.json`.
- Updated both READMEs, Skill instructions, UI metadata, tests, and generated Skill metadata for the new name.
- Added a vector cairn icon with transparent 1024 px, 400 px, and 128 px PNG exports.

## 0.1.2 - 2026-10-25

- Added a complete Simplified Chinese reference translation of the Skill instructions.
- Linked the English runtime entry and Chinese translation from both READMEs.

## 0.1.1 - 2026-10-25

- Removed runtime and workflow coupling to external Skill generation or optimization tools.
- Kept a short acknowledgement in both READMEs for design inspiration only.
- Clarified that exported drafts are independent Markdown artifacts.

## 0.1.0 - 2026-10-25

- Added a local Markdown vault initializer.
- Added evidence-backed knowledge card templates.
- Added deterministic tag and schema validation.
- Added promotion-gate checks for recurring knowledge.
- Added Skill draft export.
- Added Chinese and English documentation.
- Added a standard-library test suite.
